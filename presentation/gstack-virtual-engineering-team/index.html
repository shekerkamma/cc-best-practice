— Andrej Karpathy, January 2025

The Question

How does one person ship like a team of twenty?

Garry Tan's Answer

gstack — his open source software factory built on top of Claude Code. 23 opinionated slash-command skills that act as specialized team roles: CEO, Designer, Eng Manager, Release Manager, Doc Engineer, QA Lead, Security Officer, and more.

Section 1

The Sprint Workflow

Level: Low — a structured process that makes parallelism work.

Think → Plan → Build → Review → Test → Ship → Reflect

Think → Plan → Build → Review → Test → Ship → Reflect

How Skills Chain Together

Each skill feeds into the next. /office-hours writes a design doc that /plan-ceo-review reads. /plan-eng-review writes a test plan that /qa picks up. Nothing falls through the cracks because every step knows what came before.

Why Process Matters

Without structure, ten agents is ten sources of chaos. The sprint process is what makes parallelism work.

The Specialists

Level: Medium — 23 AI roles spanning every phase of software delivery.

Think & Plan Specialists

💡
/office-hours — YC Office Hours 6 forcing questions that reframe your product — demand reality, status quo, moat, and more
👑
/plan-ceo-review — CEO/Founder Mode Rethinks the problem from scratch, finds the 10-star product, challenges every premise
⚙
/plan-eng-review — Eng Manager Locks architecture, data flow, diagrams, edge cases — execution plan before a line is written
🎨
/plan-design-review — Senior Designer Rates every design dimension 0–10, detects AI slop patterns, ensures taste before build
⚡
/autoplan — Full Pipeline Runs CEO → design → eng review automatically in sequence — one command, three perspectives

Build & Review Specialists

🔍
/review — Staff Engineer Finds bugs that pass CI but blow up in production — SQL safety, trust boundaries, race conditions
🔬
/investigate — Debugger Systematic root-cause analysis — no fixes without investigation first
🎨
/design-review — Designer Who Codes Audits visual inconsistency, spacing, hierarchy — then fixes it with atomic commits
🌟
/design-shotgun — Design Explorer Generates 4–6 AI mockup variants with taste memory — opens a comparison board
💻
/design-html — Design Engineer Production HTML with Pretext computed layout — 30KB, zero dependencies
🤖
/codex — Second Opinion Independent review via OpenAI Codex CLI — cross-model analysis catches blind spots

Test & Ship Specialists

🏗
/qa — QA Lead Opens a real browser, clicks through flows, finds and fixes bugs with regression tests
🔒
/cso — Chief Security Officer OWASP Top 10 + STRIDE threat model — zero-noise, infrastructure-first security audit
🚚
/ship — Release Engineer Sync main, run tests, audit coverage, push, open PR — the full release checklist automated
🚀
/land-and-deploy Merges PR, waits for CI, verifies production health — no manual hand-off
📊
/canary — Post-Deploy Monitor Continuous monitoring loop after deploy — console errors, performance regressions, page health
📝
/document-release + /retro Updates all project docs to match what shipped, then runs a team-aware weekly retrospective

Power Tools

/pair-agent — Cross-Agent Coordination Share a browser between Claude, Codex, and Hermes — multi-agent workflows on the same session
🛠
/careful, /freeze, /guard — Safety Guardrails Warn before destructive commands, restrict edits to a directory, or combine both into full safety mode
🧠
/learn — Persistent Memory Compounds knowledge across sessions — the agent remembers patterns it discovers over time

Getting Started in 30 Seconds

Install

# Clone gstack into your project git clone https://github.com/garrytan/gstack .claude/gstack cd .claude/gstack && ./setup.sh

Recommended First Sprint

/office-hours → /plan-ceo-review → /review → /qa → /ship

Team Mode

Add gstack as a git submodule so the whole team gets automatic updates.

git submodule add https://github.com/garrytan/gstack

Works With

OpenClaw, Codex CLI, Cursor, Hermes, and 7 other AI coding agents. The browser session is shareable across all of them via /pair-agent.
